  > ****Blinkit Grocery Data Analysis with Power BI****

**Overview**

This repository contains a comprehensive analysis of Blinkit grocery sales data using Power BI. The analysis aims to uncover key insights into product performance, outlet characteristics, and sales trends to support data-driven decision-making for retail and supply chain optimization.

**Dataset**

The dataset includes transactional records from various Blinkit outlets, with the following key features:
* Item Attributes: Fat content, item identifier, item type, item visibility, item weight
* Outlet Attributes: Establishment year, identifier, location type (Tier 1/2/3), outlet size (Small/Medium/High), outlet type (Supermarket, Grocery Store, etc.)
* Sales Data: Item-wise sales figures and ratings

**Key Analyses Performed**

* Sales Performance: Identified top-performing product categories and outlets based on total sales.
* Outlet Comparison: Compared sales across different outlet types, sizes, and location tiers to highlight high-performing segments.
* Product Insights: Analyzed the impact of item fat content, type, and visibility on sales.
* Temporal Trends: Explored sales trends by outlet establishment year to assess the effect of outlet age on performance.
* Customer Ratings: Examined the relationship between product ratings and sales volume.

**Power BI Dashboard Features**

* Interactive visualizations for sales by product category, outlet type, and location tier
* Dynamic filtering by outlet size, year, and item attributes
* Drill-down capabilities for detailed outlet or item-level analysis
* KPI cards summarizing key metrics (total sales, average rating, top categories)

**How to Use**

* Download the Power BI dashboard file (.pbix) from this repository.
* Open the file in Power BI Desktop.
* Use the interactive filters and visuals to explore the data and extract insights relevant to your business needs.
